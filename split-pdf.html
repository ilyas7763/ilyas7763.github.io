Split PDF

Pull out the pages you need from a PDF into a new file.

    How to use

    1. Choose one PDF file.
    2. Type the pages you want, like 1-3,5.
    3. Select Split PDF, then download the new file.

    Questions

    Can I get several files? Run the tool again with different pages.
